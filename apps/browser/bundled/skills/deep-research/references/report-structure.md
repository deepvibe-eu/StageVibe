# Report structure

Use this layout for the final report unless the user asked for something else.
Keep it readable: prose first, tables only where they genuinely compare things.

```markdown
# <Title that states the finding, not the topic>

## Summary
Three to six sentences. The answer, up front.

## Context
What the question is, and what the reader needs to know to follow the rest.

## Findings
One `##` section per sub-question from the analysis phase. Each section ends
with an assessment, not just a list of facts.

## Contradictions and uncertainty
Where sources disagree, what is still unknown, and how that changes the
conclusion.

## Sources
Numbered list of sources with title, link, and access date.
```

Rules:

- The title states the conclusion; a reader who only reads it should still
  learn something true.
- Claims carry a marker pointing at the source list (`[3]`), and dates matter.
- Numbers keep their unit and currency; don't round away the distinction that
  makes them meaningful.
- No filler sections ("Introduction", "Conclusion" that only repeats the
  summary).
